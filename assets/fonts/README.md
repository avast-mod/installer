`RobotoCondensed-Regular.ttf` and `RobotoCondensed-Bold.ttf` are the 400 and 700 weights of the variable Roboto Condensed font, made static with fontTools. `fs-tahoma-8px-bold.ttf` is generated from `fs-tahoma-8px.ttf` by `make_bold.py`, and `fs-tahoma-8px-italic.ttf` and `fs-tahoma-8px-bold-italic.ttf` from those two by `make_italic.py` (AVaSt Core uses them for README text). The other files are unchanged.
